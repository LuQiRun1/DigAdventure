# Game Asset Generator

## 1. 默认图片规格

- 单个 Sprite：128×128 px。
- 默认图集：4×4，即 512×512 px。
- 图片格式：PNG。
- 色彩模式：RGBA。
- 必须使用真正透明的 Alpha 背景。
- 去除额外的黑色外描边。
- 保持 Q 版奇幻冒险游戏美术风格。
- 用户明确指定其他尺寸时，以用户要求为准。

## 2. 图集规范

- 每个素材严格占据一个 128×128 网格。
- 素材必须居中对齐。
- 不允许素材跨越网格。
- 不允许主体被裁切。
- 保留适当安全边距。
- 同一动画所有帧保持统一比例和锚点。
- 不添加多余网格线和背景。

## 3. 透明背景

- 输出真实透明背景，不得使用棋盘格模拟透明。
- 检查 Alpha 通道。
- 清除素材外部背景残留。
- 保留主体边缘的自然半透明像素。
- 避免白边、黑边和彩色溢边。

## 4. 美术风格

- Q 版奇幻冒险风格。
- 明亮、协调的色彩。
- 柔和立体光影。
- 去除额外黑色外描边。
- 不擅自改变已有角色设计。
- 所有 UI 和游戏资源保持统一视觉语言。
- 默认不采用机器人科技风格。

## 5. 图片后处理

生成图片后必须执行实际处理：

1. 检查原始分辨率。
2. 处理透明背景。
3. 清理外部描边和背景残留。
4. 按照目标尺寸裁切。
5. 调整单格至 128×128。
6. 按网格组合图集。
7. 使用 PNG RGBA 格式导出。

优先使用 Python Pillow 进行处理。
缩放采用高质量重采样，避免不必要的模糊。

## 6. 质量检查

最终文件必须检查：

- 图片实际宽高。
- PNG 文件格式。
- RGBA 色彩模式。
- Alpha 通道有效性。
- 背景透明度。
- 外部描边残留。
- 图集网格对齐。
- 素材完整性。
- 文件能否正常打开。

不能仅凭文件扩展名判断是否符合规范。

## 7. 最终交付

每次生成资源必须：

1. 提供最终 PNG 文件。
2. 提供真实可用的下载链接。
3. 报告实际像素尺寸。
4. 报告图集布局。
5. 报告透明通道检查结果。
6. 不得将未经处理的原始图片称为最终成品。

如果检查不通过，继续处理或明确说明问题，不得虚报完成。
